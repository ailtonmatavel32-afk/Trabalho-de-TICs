# Escola sem Violência — Website educativo

Website académico sobre violência verbal e física entre alunos.

## Ficheiros
- `index.html` — estrutura e conteúdo do website.
- `style.css` — design responsivo, cores, tipografia e ilustração SVG.
- `script.js` — menu móvel e ano automático no rodapé.

## Como visualizar
Abra `index.html` num navegador. O site funciona em telemóveis e computadores.
A tipografia usa Google Fonts quando existe ligação à Internet; se não houver, serão usadas fontes de reserva.

## Publicar gratuitamente com GitHub Pages
1. Crie um repositório público no GitHub.
2. Carregue os três ficheiros (`index.html`, `style.css`, `script.js`) para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)` e carregue em **Save**.
6. Aguarde a publicação. O endereço será semelhante a `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Nota académica
O conteúdo foi organizado segundo as orientações do documento fornecido: página inicial, introdução, objectivos, desenvolvimento, soluções/prevenção, recomendações, conclusão e referências bibliográficas. As fontes externas são institucionais. Os dados globais estão identificados como globais; não foram inventados resultados de entrevistas ou questionários em Moçambique.
